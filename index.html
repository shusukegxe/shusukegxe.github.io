Sobre MiniFeather

MiniFeather es un cliente para MiniBlox. He trabajado en varias partes del ecosistema:

• MiniFeather-Client — Cliente personalizado para MiniBlox con recursos gráficos, texturas y fuentes.

• mfaccs — Sistema de gestión de cuentas, skins y capas (capes). Proyecto activo en Python con más de 160 commits, incluyendo skins, capes y automatización.

• Integración con PixelVortex, el launcher que desarrollé para facilitar el acceso a MiniBlox y herramientas relacionadas.
